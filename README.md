# Lama Gongdu Cycle

A bilingual catalogue of the fourteen volumes of the Lama Gongdu cycle. Search in English or Tibetan, open a volume to explore its texts, and expand the biography of Sangye Lingpa. The original collection and purchase links are included in their respective entries.

The catalogue, portraits and fonts are bundled locally. The portraits follow the source edition from [Tsadra Commons](https://commons.tsadra.org/images/7/7d/Sangye_Lingpa.jpg) and [Wikimedia Commons](https://upload.wikimedia.org/wikipedia/commons/thumb/e/ea/Sanggye_Lingpa_%281705-1735%29._Tibet%2C_19th_century%2C_Rubin_Museum_of_Art..jpg/960px-Sanggye_Lingpa_%281705-1735%29._Tibet%2C_19th_century%2C_Rubin_Museum_of_Art..jpg).

Run `npm ci` and `npm run dev` locally. `npm run lint` checks TypeScript and `npm run build` writes the static site to `dist`. GitHub Actions deploys pushes to `main` to GitHub Pages.
